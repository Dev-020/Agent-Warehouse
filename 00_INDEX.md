# Warehouse Index

## How to read this

Each item has an **ID** (`<kind>/<name>`, never changes), a **version** (SemVer), a **status**
(`draft`, `canonical`, `deprecated`), a one-line **summary**, and **applies to** (the kinds of project
it fits). The Catalog and Recent releases sections are generated by `warehouse index` between the
`warehouse:*` markers; everything else in this note is hand-written and preserved.
